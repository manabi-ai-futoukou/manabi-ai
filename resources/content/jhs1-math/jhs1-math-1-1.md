# 符号のついた数

## この授業のねらい

- 0 より小さい数があることを知り、「正の数」「負の数」という言葉で表せるようになります。
- 反対の性質をもつ量を、正の数と負の数を使って表せるようになります。

## 0 より小さい数

冬の天気予報で、「あすの最低気温は氷点下 3 度でしょう」という言い方を聞いたことはないでしょうか。

水がこおる温度を 0 ℃ と決めると、それより 3 ℃ 低い温度は 0 ℃ よりも下になります。この温度を $-3$ ℃ と書き、「マイナス 3 度」と読みます。

小学校で学んだ数は、0 と、0 より大きい数でした。中学校では、ここに **0 より小さい数** が加わります。

- 0 より大きい数を **正の数** といいます。正の数は、**正の符号 $+$**（プラス）を付けて $+5$ のように表すことがあります。$+5$ と $5$ は同じ数です。
- 0 より小さい数を **負の数** といいます。負の数は、**負の符号 $-$**（マイナス）を付けて $-3$ のように表します。
- **0 は、正の数でも負の数でもありません。**

これまで「たす」「ひく」の記号として使ってきた $+$ と $-$ を、ここでは数の **符号** として使っています。同じ記号に 2 つの役割があることを、頭に入れておきましょう。

## 数のなかま分け

整数は、次の 3 つに分けられます。

| 負の整数 | 0 | 正の整数 |
| :-: | :-: | :-: |
| $\cdots,\ -3,\ -2,\ -1$ | $0$ | $1,\ 2,\ 3,\ \cdots$ |

正の整数 $1,\ 2,\ 3,\ \cdots$ のことを **自然数** ともいいます。0 は自然数に入りません。

小数や分数にも負の数があります。例えば、$-0.5$ や $-\dfrac{2}{3}$ は負の数です。

## 反対の性質をもつ量

負の数を使うと、**たがいに反対の性質をもつ量** を、1 つの言葉でまとめて表せます。

例えば、東西にのびる道で「東へ 3 km 進むこと」を $+3$ km と表すことにします。すると、反対向きの「西へ 2 km 進むこと」は $-2$ km と表せます。

| 正の数で表すと決めたもの | 負の数で表されるもの |
| :-- | :-- |
| 東へ進む | 西へ進む |
| 収入 | 支出 |
| 増える | 減る |
| 基準より高い | 基準より低い |

どちらを正とするかは、最初に自分で決めます。大切なのは、**基準（0 にあたるところ）と、正の向きをはっきりさせること** です。

また、ある基準を決めて、そこからの多い・少ないを表すこともできます。1 日の読書の目標を 30 分と決めたとき、40 分読んだ日は目標より 10 分多いので $+10$ 分、25 分読んだ日は 5 分少ないので $-5$ 分と表せます。

## 例題

次の数量を、正の符号または負の符号を使って表しましょう。

1. 0 ℃ より 4.5 ℃ 低い温度
2. 「北へ 6 m 進むこと」を $+6$ m と表すとき、「南へ 8 m 進むこと」

**考え方**

1. 0 ℃ より低い温度は負の数で表します。答えは $-4.5$ ℃ です。
2. 北へ進むことを正の数で表しているので、反対の南へ進むことは負の数になります。答えは $-8$ m です。

## 確かめ問題

1. 次の数の中から、負の数をすべて選びましょう。
   $+7,\quad -2,\quad 0,\quad -0.3,\quad \dfrac{5}{2},\quad -\dfrac{4}{5}$
2. 次の数の中から、自然数をすべて選びましょう。
   $-3,\quad 0,\quad 1,\quad 2.5,\quad 8$
3. 「200 円の収入」を $+200$ 円と表すとき、「350 円の支出」はどのように表せますか。
4. 「$-5$ kg 重い」を、負の数を使わない言い方に直しましょう。

### 答え

1. $-2,\quad -0.3,\quad -\dfrac{4}{5}$
2. $1,\quad 8$
3. $-350$ 円
4. 5 kg 軽い

## ノートに書いてみましょう

- 正の数・負の数・0 の関係を、自分の言葉と図で説明してみましょう。
- 身のまわりで、負の数が使われている場面を探してみましょう。気温のほかに、どんなものがあるでしょうか。
- 理科や社会で出てくる量（標高と海面下の深さ、年表の「紀元前」、国と国の時差など）は、何を基準（0）にしているでしょうか。負の数とのつながりを考えてみましょう。
