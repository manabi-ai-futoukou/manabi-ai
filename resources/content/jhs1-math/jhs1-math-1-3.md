# 加法

## この授業のねらい

- 正の数・負の数のたし算（加法）の意味を、数直線の上の動きとして説明できるようになります。
- 同じ符号どうし、ちがう符号どうしの 2 つの数の和を求められるようになります。
- 加法の交換法則と結合法則を使って、くふうして計算できるようになります。

## 数直線の上を動いて考える

たし算のことを **加法** といい、加法の結果を **和** といいます。

前の授業で学んだ数直線を使って、加法を「動き」として考えましょう。**正の数をたすことは右へ動くこと、負の数をたすことは左へ動くこと** と決めます。出発点はいつも原点（0）です。

まず、$(+2) + (+3)$ を考えます。原点から右へ 2 動き、そこからさらに右へ 3 動きます。

```numberline
{"min": -7, "max": 7, "arrows": [{"from": 0, "to": 2, "label": "+2", "color": "red"}, {"from": 2, "to": 5, "label": "+3", "color": "red"}], "points": [{"at": 5, "label": "答え", "color": "green"}]}
```

着いたところは $+5$ です。ですから、$(+2) + (+3) = +5$ です。

次に、$(-2) + (-3)$ を考えます。原点から左へ 2 動き、そこからさらに左へ 3 動きます。

```numberline
{"min": -7, "max": 7, "arrows": [{"from": 0, "to": -2, "label": "-2", "color": "blue"}, {"from": -2, "to": -5, "label": "-3", "color": "blue"}], "points": [{"at": -5, "label": "答え", "color": "green"}]}
```

着いたところは $-5$ です。ですから、$(-2) + (-3) = -5$ です。

## 同じ符号の 2 つの数の和

上の 2 つの例では、同じ向きに 2 回動いたので、動いた距離は合わせて $2 + 3 = 5$ でした。向きは、もとの数と同じです。

> **同じ符号の 2 つの数の和**
> 絶対値の和に、共通の符号を付ける。

## ちがう符号の 2 つの数の和

$(+3) + (-5)$ を考えます。原点から右へ 3 動き、そこから向きを変えて左へ 5 動きます。

```numberline
{"min": -7, "max": 7, "arrows": [{"from": 0, "to": 3, "label": "+3", "color": "red"}, {"from": 3, "to": -2, "label": "-5", "color": "blue"}], "points": [{"at": -2, "label": "答え", "color": "green"}]}
```

着いたところは $-2$ です。右へ 3、左へ 5 動いたので、左へ動いた分のほうが $5 - 3 = 2$ だけ多く、原点の左側に着きました。

$$(+3) + (-5) = -(5 - 3) = -2$$

> **ちがう符号の 2 つの数の和**
> 絶対値の大きいほうから小さいほうをひき、絶対値の大きいほうの符号を付ける。

絶対値が等しく、符号がちがう 2 つの数の和は 0 になります。右へ 4 動いて左へ 4 動けば、もとの原点にもどるからです。

$$(+4) + (-4) = 0$$

また、0 をたしても数は変わりません。0 に数をたすと、その数になります。

$$(-6) + 0 = -6 \qquad 0 + (-6) = -6$$

## 加法の計算法則

正の数・負の数の加法でも、小学校で学んだ次の法則が成り立ちます。

- **加法の交換法則**　$a + b = b + a$
- **加法の結合法則**　$(a + b) + c = a + (b + c)$

この 2 つの法則があるので、いくつかの数の加法は、**数の順序や組み合わせを変えて計算してもかまいません。** 正の数どうし、負の数どうしを先にまとめると、計算が楽になります。

## 例題

次の計算をしましょう。

$$(+8) + (-5) + (+2) + (-9)$$

**考え方**

正の数どうし、負の数どうしを先に集めます。

$$
\begin{aligned}
(+8) + (-5) + (+2) + (-9) &= (+8) + (+2) + (-5) + (-9) \\
&= (+10) + (-14) \\
&= -(14 - 10) \\
&= -4
\end{aligned}
$$

## 確かめ問題

1. 次の計算をしましょう。
   (1) $(+4) + (+9)$　　(2) $(-6) + (-7)$
   (3) $(+5) + (-8)$　　(4) $(-3) + (+10)$
2. 次の計算をしましょう。
   (1) $(-12) + (+12)$　　(2) $0 + (-5)$
3. 次の計算をしましょう。
   $(-7) + (+15) + (-3) + (+5)$
4. 小数や分数の加法も、整数のときと同じ決まりで計算できます。次の計算をしましょう。
   (1) $(-1.5) + (-2.3)$　　(2) $\left(+\dfrac{1}{2}\right) + \left(-\dfrac{3}{4}\right)$

### 答え

1. (1) $+13$　　(2) $-13$　　(3) $-3$　　(4) $+7$
2. (1) $0$　　(2) $-5$
3. $(+15) + (+5) + (-7) + (-3) = (+20) + (-10) = +10$
4. (1) $-3.8$　　(2) $-\dfrac{1}{4}$
