# The Number Line and Absolute Value

## Goals of This Lesson

- You will be able to show positive and negative numbers as points on a number line.
- You will be able to use inequality signs to show which number is greater or smaller.
- You will understand what absolute value means and be able to use it when comparing numbers.

## The Number Line

In the last lesson, you learned that numbers smaller than 0 are called negative numbers. In this lesson, we will **line numbers up on a straight line** and think about them.

Draw a straight line, choose a point to be the standard, and match it with the number 0. This point is called the **origin**. From the origin, mark tick marks at equal spacing to the right: $1,\ 2,\ 3,\ \cdots$. The number lines you used in elementary school went only this far.

In junior high school, we also mark tick marks at the same spacing **to the left** of the origin, and match them with $-1,\ -2,\ -3,\ \cdots$.


On a number line, the direction to the right is called the **positive direction**, and the direction to the left is called the **negative direction**.

Not only integers but also decimals and fractions can be shown on a number line. For example, $-2.5$ is the point exactly halfway between $-2$ and $-3$.

```numberline

```

In the figure above, the number matching point A is $-2.5$, and the number matching point B is $+1.5$.

## Comparing Numbers

On a number line, **the farther right a number is, the greater it is, and the farther left it is, the smaller it is**. This rule does not change even for negative numbers.

For example, comparing $-3$ and $+2$, $+2$ is farther to the right, so $+2$ is the greater number. We use inequality signs to write this as follows.

$$-3 < +2 \qquad \text{or} \qquad +2 > -3$$

What about $-4$ and $-1$? Thinking in terms of temperature, $-1$ ℃ is warmer than $-4$ ℃, and on the number line too, $-1$ is farther to the right. So,

$$-4 < -1$$

It is easy to think, "4 is greater than 1, so $-4$ is greater," so let's get into the habit of checking on a number line.

When comparing three numbers, we keep the inequality signs pointing the same way and write the numbers in order from smallest to greatest (or from greatest to smallest).

$$-4 < -1 < +3$$

To sum up:

- **A positive number is greater than 0, and a negative number is smaller than 0.**
- **A positive number is greater than a negative number.**

## Absolute Value

On a number line, **the distance between the point matching a number and the origin** is called the **absolute value** of that number.

```numberline
{"min":-5,"max":5,"points":[{"at":-3,"label":"-3","color":"blue"},{"at":3,"label":"+3","color":"red"}],"arrows":[{"from":0,"to":-3,"label":"Distance 3","color":"blue"},{"from":0,"to":3,"label":"Distance 3","color":"red"}]}
```

Both $+3$ and $-3$ are at a distance of 3 from the origin. So the absolute value of $+3$ is 3, and the absolute value of $-3$ is also 3. You can think of the absolute value as **the number with its sign removed**. The absolute value of 0 is 0.

Because absolute value is a distance, it is never negative.

Using absolute value, we can restate how to compare numbers as follows.

- **For positive numbers, the greater the absolute value, the greater the number.**
- **For negative numbers, the greater the absolute value, the smaller the number.**

For $-4$ and $-1$, the absolute values are 4 and 1. Since both are negative numbers, $-4$, which has the greater absolute value, is the smaller number.

## Worked Example

1. Give all the numbers whose absolute value is 5.
2. Use an inequality sign to show which is greater, $-7$ or $-9$.

**How to Think About It**

1. There is one point on the right of the origin and one on the left that are at a distance of 5 from the origin. The answers are $+5$ and $-5$.
2. The absolute values are 7 and 9. For negative numbers, the greater the absolute value, the smaller the number, so $-9$ is smaller. The answer is $-9 < -7$.

   (1) $+3,\ -5$　　(2) $-2,\ -8$　　(3) $-0.1,\ 0$

   $+2,\quad -3,\quad 0,\quad -1.5$

### Answers

1. $8,\quad 6,\quad 2.5,\quad 0$
2. (1) $-5 < +3$　　(2) $-8 < -2$　　(3) $-0.1 < 0$
3. $-3,\quad -1.5,\quad 0,\quad +2$
