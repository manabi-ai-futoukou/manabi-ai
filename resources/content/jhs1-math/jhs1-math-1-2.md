# 数直線と絶対値

## この授業のねらい

- 正の数と負の数を、数直線の上の点として表せるようになります。
- 数の大小を、不等号を使って表せるようになります。
- 絶対値の意味を理解し、数の大小を比べるときに使えるようになります。

## 数直線

前の授業では、0 より小さい数を負の数ということを学びました。この授業では、数を **直線の上に並べて** 考えます。

まっすぐな線を引き、基準になる点を決めて、数 0 を対応させます。この点を **原点** といいます。原点から右へ、同じ間隔で $1,\ 2,\ 3,\ \cdots$ と目もりを付けます。小学校で使った数直線はここまででした。

中学校では、原点から **左へも** 同じ間隔で目もりを付けて、$-1,\ -2,\ -3,\ \cdots$ を対応させます。

```numberline
{"min": -5, "max": 5, "points": [{"at": 0, "label": "原点"}], "ranges": [{"from": 0.3, "to": 5, "label": "正の方向 →", "color": "red"}, {"from": -5, "to": -0.3, "label": "← 負の方向", "color": "blue"}]}
```

数直線では、右の向きを **正の方向**、左の向きを **負の方向** といいます。

整数だけでなく、小数や分数も数直線の上に表せます。例えば $-2.5$ は、$-2$ と $-3$ のちょうどまん中の点です。

```numberline
{"min": -5, "max": 5, "points": [{"at": -2.5, "label": "A", "color": "blue"}, {"at": 1.5, "label": "B", "color": "red"}]}
```

上の図で、点 A に対応する数は $-2.5$、点 B に対応する数は $+1.5$ です。

## 数の大小

数直線の上では、**右にある数ほど大きく、左にある数ほど小さく** なります。この決まりは、負の数でも変わりません。

例えば、$-3$ と $+2$ では、$+2$ のほうが右にあるので、$+2$ のほうが大きい数です。このことを、不等号を使って次のように表します。

$$-3 < +2 \qquad \text{または} \qquad +2 > -3$$

$-4$ と $-1$ ではどうでしょうか。気温で考えると、$-4$ ℃ よりも $-1$ ℃ のほうが暖かく、数直線でも $-1$ が右にあります。ですから、

$$-4 < -1$$

です。「4 のほうが 1 より大きいから $-4$ のほうが大きい」と考えてしまいやすいところなので、数直線で確かめる習慣を付けましょう。

3 つの数の大小は、不等号の向きをそろえて、小さい順（または大きい順）に並べて書きます。

$$-4 < -1 < +3$$

まとめると、次のようになります。

- **正の数は 0 より大きく、負の数は 0 より小さい。**
- **正の数は、負の数より大きい。**

## 絶対値

数直線の上で、**ある数に対応する点と原点との距離** を、その数の **絶対値** といいます。

```numberline
{"min": -5, "max": 5, "points": [{"at": -3, "label": "-3", "color": "blue"}, {"at": 3, "label": "+3", "color": "red"}], "arrows": [{"from": 0, "to": -3, "label": "距離 3", "color": "blue"}, {"from": 0, "to": 3, "label": "距離 3", "color": "red"}]}
```

$+3$ も $-3$ も、原点からの距離は 3 です。ですから、$+3$ の絶対値は 3、$-3$ の絶対値も 3 です。絶対値は、**その数から符号を取りさったもの** と考えることができます。0 の絶対値は 0 です。

絶対値は距離なので、負の数になることはありません。

絶対値を使うと、数の大小を次のように言いかえられます。

- **正の数は、絶対値が大きいほど大きい。**
- **負の数は、絶対値が大きいほど小さい。**

$-4$ と $-1$ では、絶対値は 4 と 1 です。負の数どうしなので、絶対値の大きい $-4$ のほうが小さい数です。

## 例題

1. 絶対値が 5 である数をすべて答えましょう。
2. $-7$ と $-9$ の大小を、不等号を使って表しましょう。

**考え方**

1. 原点からの距離が 5 である点は、原点の右と左に 1 つずつあります。答えは $+5$ と $-5$ です。
2. 絶対値は 7 と 9 です。負の数は絶対値が大きいほど小さいので、$-9$ のほうが小さくなります。答えは $-9 < -7$ です。

## 確かめ問題

1. 次の数の絶対値を答えましょう。
   $+8,\quad -6,\quad -2.5,\quad 0$
2. 次の 2 つの数の大小を、不等号を使って表しましょう。
   (1) $+3,\ -5$　　(2) $-2,\ -8$　　(3) $-0.1,\ 0$
3. 次の数を、小さい順に並べましょう。
   $+2,\quad -3,\quad 0,\quad -1.5$
4. 絶対値が 2.5 より小さい整数を、すべて答えましょう。

### 答え

1. $8,\quad 6,\quad 2.5,\quad 0$
2. (1) $-5 < +3$　　(2) $-8 < -2$　　(3) $-0.1 < 0$
3. $-3,\quad -1.5,\quad 0,\quad +2$
4. $-2,\quad -1,\quad 0,\quad 1,\quad 2$

- 「負の数は、絶対値が大きいほど小さい」のはなぜでしょうか。自分の言葉で説明してみましょう。
